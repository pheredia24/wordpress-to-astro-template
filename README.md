# Plantilla: migración WordPress → Astro

Repositorio base para arrancar proyectos de migración de sitios WordPress a Astro + Sanity + Vercel.

**Uso:** Seguir la guía paso a paso en **[guide.md](./guide.md)**. El handoff se rellena en **[docs/HANDOFF.md](./docs/HANDOFF.md)** (sustituir los placeholders `{{...}}` al cerrar la Fase 7).

**Requisitos:** Node.js, [Vercel CLI](https://vercel.com/cli), [Sanity CLI](https://www.sanity.io/docs/getting-started-with-sanity-cli), [GitHub CLI](https://cli.github.com/) (opcional, para crear el repo). El humano debe hacer `vercel login`, `sanity login` y `gh auth login` (o equivalente) antes de que el agente ejecute la guía.

**Cómo empezar un nuevo proyecto:** "Use this template" en GitHub (o clonar este repo), pegar la **URL de la web origen**, y ejecutar la Preparación y la Fase 1 según la guía.
